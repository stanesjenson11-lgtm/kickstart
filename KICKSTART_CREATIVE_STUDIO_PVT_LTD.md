## 04. VISUAL DIRECTION

### BLACK & WHITE ONLY

The website should use a monochrome visual identity.

Primary colours

Black: #050505

White: #FFFFFF

Off-white: #F5F5F3

Dark Grey: #151515

Light Grey: #A0A0A0

No unnecessary accent colours.

No colourful gradients.

The visual interest should come from:

Photography

Typography

Contrast

Motion

Negative space

Composition

## 05. DESIGN STYLE

The visual direction should combine:

Premium creative studio
+
Editorial magazine
+
Film production house
+
Modern corporate brand

Reference feeling:

Cinematic

High-end

Sophisticated

Minimal

Bold

Art-directed

Avoid:

Generic agency templates

Excessive rounded cards

Stock images

Cheap-looking icons

Excessive gradients

Neon colours

Excessive glassmorphism

Overly complicated animations

Cluttered layouts

## 06. TYPOGRAPHY

Use a modern sans-serif as the primary typeface.

Possible direction:

Inter Tight / Manrope / Neue Montreal / similar premium grotesk

Optional secondary editorial font:

Instrument Serif / similar editorial serif

Use the serif sparingly.

Typography hierarchy

Hero:

Extremely large display typography.

Section headings:

Large, bold, high contrast.

Body:

Clean and highly readable.

Labels:

Small uppercase typography with letter spacing.

## 25. ANIMATION DIRECTION

Animations should be subtle and cinematic.

Required:

Smooth scrolling

Text reveal

Image reveal

Image scale on scroll

Subtle hover effects

Video autoplay when appropriate

Navigation transition

Section transitions

Avoid:

Excessive parallax

Spinning objects

Particle effects

Bouncing buttons

Long loading animations

Excessive cursor effects

The animation should make the site feel expensive, not distracting.

## 26. IMAGE TREATMENT

Photography is a major part of the brand.

Preferred:

High contrast black & white

Use:

Strong shadows

Dramatic lighting

Clean compositions

Editorial cropping

Large images

Full-bleed photography

Avoid generic stock photography wherever possible.

Actual Kickstart work should dominate the website.

## 31. FINAL DESIGN PRINCIPLE

The most important instruction:

### DO NOT MAKE THIS LOOK LIKE A GENERIC DIGITAL AGENCY WEBSITE.

The site should feel like a premium creative production house.

The hierarchy should be:

### IMPACT → WORK → TRUST → SERVICES → PROCESS → CONTACT

Not:

### ABOUT US → SERVICES → SERVICES → SERVICES → CONTACT

The website should sell the quality and perception of Kickstart before explaining everything Kickstart does.

## 32. SUCCESS CRITERIA

When someone lands on the website, within approximately 5 seconds they should understand:

WHO:
Kickstart Creative Studio

WHAT:
Premium media production + advertising + social media

FOR WHOM:
Businesses and ambitious brands

WHY:
Exceptional visual craft + strategic thinking

WHAT NEXT:
Start a project

If those five things are clear, the website is doing its job.
